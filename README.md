# 🌌 Dark Anime Wallpapers App

A sleek, AMOLED-themed Dark Anime Wallpaper application built with modern Flutter. Designed for zero-lag performance, high monetization, and 100% Android 10 to 14+ compatibility.

---

## ✨ Features Included

- 📱 **Set Wallpaper:** Choose between **Home Screen**, **Lock Screen**, or **Both** (Uses modern `async_wallpaper`).
- 💾 **Save to Gallery:** Directly writes to Android MediaStore with zero permission crashes on modern Android 10-14+ (Uses `gal`).
- 🖤 **AMOLED Dark Design:** Deep blacks, neon purple highlights, fast image caching, and pinch-to-zoom.
- 📂 **Dynamic Categories:** Filter by *Cyberpunk*, *Samurai*, *Aesthetic*, *Fantasy*, *Monochrome*, and *Villains*.
- ❤️ **Favorites System:** Save favorite wallpapers locally on device.
- 💰 **Google AdMob Monetization:** Pre-configured with bottom Banner Ads and transition Interstitial Ads (with safe test IDs).
- ☁️ **Dynamic JSON Catalog:** Update or add wallpapers remotely without updating the app on the Play Store.

## 🚀 How to Build & Get Your APK in Your Browser (No Terminal Required)

### Step 1: Create a Free GitHub Repository
1. Go to [github.com](https://github.com) and click **New Repository**.
2. Name it `dark-anime-wallpapers` and set it to **Public**.

### Step 2: Upload Project Files
1. In your GitHub repository, click **Add file** $\rightarrow$ **Upload files**.
2. Drag and drop all the project files (`pubspec.yaml`, `wallpapers.json`, the `.github` folder, `android` folder, and `lib` folder).
3. Click **Commit changes**.

### Step 3: Download Your APK!
1. Go to the **Actions** tab in your GitHub repository.
2. You will see a workflow named **Build Android APK** running.
3. Once completed (takes ~2-3 minutes), click on the run and look under **Artifacts**.
4. Download the `dark-anime-wallpapers-apk.zip`, unzip it, and send the `.apk` to your Android phone to install and test!
